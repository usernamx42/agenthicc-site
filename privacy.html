Privacy policy

Effective 8 October 2026. AGENTHICC is an editorial channel operated from Kazakhstan. This page describes its public website and the channel owner’s private production client.

The public website

This static site does not offer user accounts, forms, advertising cookies or third-party analytics. GitHub Pages hosts the site and may process connection information under GitHub’s privacy statement. Following external links is subject to those services’ policies.

YouTube API Services

Our private production client uses YouTube API Services. It uses OAuth authorization to manage the owner’s channel uploads, metadata, thumbnails, captions and playlists, and to read the owner’s YouTube Analytics and Reporting data. Google’s handling of data is described in the Google Privacy Policy.

Credentials are held in the owner’s macOS Keychain or a local protected configuration. Private production files, credentials and API data are not part of this website. Public assessments contain original editorial analysis; YouTube metrics, if shown, are presented unaltered and identified.

Retention and revocation

Other channels’ API metadata is used only as a topic-coverage signal and purged after 23 days; it is refreshed or deleted within 30 days. Authorized own-channel Analytics and Reporting data may be retained for editorial history while authorization remains valid. Authorization and deletion status are reviewed at least every 30 days. Data is not sold.

The owner can revoke the client’s access at any time through Google account security settings. Revocation prevents new authorized API access; the owner can also remove the local Keychain entries and stored channel data. We do not collect visitors’ Google credentials or offer this client as a public sign-in service.

Requests and changes

For a public-site issue, use the website issue tracker. Do not post passwords, account identifiers or private personal data in a public issue. An owner-managed private contact route will be added with the channel launch. Material changes to this policy will be dated here.
